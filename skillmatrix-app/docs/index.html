SkillMatrix — Employee Skill Matrix Management System

A centralized platform that helps IT companies quickly identify employees with the right skills for new projects — replacing scattered resumes, spreadsheets, and emails with one searchable, role-aware system.

Live demo ↗ View source on GitHub ↗

The problem

In large IT companies, finding the right people for a new project is slow because skill information is scattered across resumes, emails, spreadsheets, and disconnected internal tools. Managers waste time chasing down who knows what, and good matches get missed simply because nobody could search for them.

What it does

Employee skill profiles
Technical skills, domain knowledge, experience, and proficiency level for every employee, in one place.
Standardized skill taxonomy
Detects and merges duplicate skill names ("AWS" vs "Amazon Web Services") so search results don't fragment.
Search & match engine
Manual skill/proficiency filters, or a plain-English query parsed via a local Ollama model (with a built-in fallback when it isn't available).
Project-based staffing
Save what a project needs, rank candidates against it, and assign or unassign people with one click.
Reports
Bench utilization, skill-gap analysis against active projects, and headcount by department.
Role-based access
Employees manage their own profile; managers search and staff; admins control the roster and taxonomy.

Roles

Employee
Views and edits only their own profile.
Manager
Read-only roster, search, projects, reports.
Admin / HR
Full control — roster, taxonomy, backups.

Tech stack

Node.js (http module, zero dependencies) SQLite (node:sqlite) REST API HTML / CSS / vanilla JS frontend Ollama (optional NL search) Rendered on Render

How it was built

1. Employee profiles & skill taxonomy
Core data model — profiles, standardized skill list, unmapped-skill detection and merge tooling.
2. Search & match
Skill/proficiency filtering with ranked results by match percentage and level strength.
3. Roles & access
Employee / Manager / Admin permission tiers, enforced on both the UI and the API.
4. Project-based staffing
Saved project requirements, candidate ranking, and one-click assignment.
5. Reports
Utilization, skill-gap, and department breakdowns pulled live from the database.
6. Full-stack rebuild
Moved from browser-only storage to a real Node.js + SQLite backend with a REST API, plus optional Ollama-powered natural-language search.
